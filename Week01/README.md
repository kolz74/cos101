# COS101 Practical - Week 1

This folder contains Python practice files based on the Week 1 notes.

## Files
- `hello.py` - first saved Python script
- `personal_introduction.py` - personal and academic introduction
- `course_display.py` - displays course information and comments
- `text_and_calculation.py` - compares printed text with arithmetic
- `rectangle_area.py` - calculates a rectangle's area (12 m by 7 m)
- `purchase_total.py` - calculates the cost of four pens at ₦250 each
- `debugging_exercise.py` - corrected version of the debugging task
- `classroom_chairs.py` - take-home task: 6 rows with 8 chairs per row

## Run a file on macOS
Open Terminal, move into this folder, then run for example:

```bash
python3 hello.py
```

Replace `hello.py` with the name of another file to run it.
