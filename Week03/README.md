# COS101 Practical — Week 3

**Topic:** Conditional Statements and Decision-Making in Python

## Files
- `comparison_demo.py` — comparison operators.
- `pass_checker.py` — pass/fail and score-range validation.
- `grade_classifier.py` — classroom grade bands.
- `safe_calculator.py` — arithmetic choices and division-by-zero protection.
- `electricity_bill.py` — fictional tiered classroom electricity tariff.
- `number_classifier.py` — positive, negative, or zero.
- `even_or_odd.py` — even/odd check.
- `larger_of_two.py` — compare two numbers.
- `discount_calculator.py` — supplied classroom discount policy.
- `registration_attendance.py` — registration and attendance eligibility.
- `student_result_checker.py` — assessed result and progression checker.
- `weekly_expenses_budget.py` — Week 2 expense calculator extension.

## Running a program
Open Terminal, move into this folder, then run a file. For example:

```bash
python3 grade_classifier.py
```

Run each file separately. Enter numeric values when a program asks for a number. The Week 3 notes say handling text that cannot be converted to a number will be covered in Week 9.

## Important note
The electricity rates and discount rules are fictional classroom values supplied in the practical notes; they are not current provider rates or general commercial advice.
