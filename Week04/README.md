# COS101 Practical — Week 4
**Topic:** Loops and Repeated Calculations in Python

This folder contains the Week 4 practical programs, including the assessed `student_score_summary.py` and take-home `daily_sales_summary.py`.

## Run a program
1. Open Python IDLE.
2. Choose **File → Open** and select a `.py` file in this folder.
3. Choose **Run → Run Module** or press **F5**.
4. Enter the requested values in the Python Shell.

The examples follow the notes' assumption that numeric prompts receive numbers in the expected format. They do not use `try`/`except`, which is taught later.

See `student_score_summary_submission.md` for the assessed practical's IPO table, pseudocode, test cases, and counter/accumulator explanation.
